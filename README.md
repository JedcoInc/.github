# JEDCO organization profile

This repository holds the public GitHub organization profile for [JEDCO](https://github.com/JedcoInc).

GitHub displays `profile/README.md` on the organization's Overview page. Profile images are stored in `profile/assets/` so the page does not depend on external image hosting.

## Brand and content sources

Company information and original imagery were sourced from the [JEDCO website](https://www.jedinc.com/) on October 1, 2026.

- Company background: https://www.jedinc.com/about/
- Manufacturing processes: https://www.jedinc.com/capabilities/
- Quality information: https://www.jedinc.com/quality-assurance/
- Address and phone: https://www.jedinc.com/contact/
- Logo: https://www.jedinc.com/wp-content/uploads/2020/02/jedco-fixed.jpg
- Component photograph: https://www.jedinc.com/wp-content/uploads/2019/10/M5D_2078-copy.jpg
- Website blue: `#004E97`; logo blue accent: `#008FB8`; charcoal: `#333333`.

The banner incorporates the original logo and photograph without changing the logo artwork. The avatar places the original logo on a square white background suitable for GitHub.

Keep company facts aligned with the website. Link to the quality page rather than duplicating certificates whose validity may change. Staffing, shift counts, and facility totals are intentionally omitted because the source pages give differing figures.

The logo and photographs are JEDCO company assets. This repository does not grant a reuse license for them.
